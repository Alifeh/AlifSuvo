# Reposition the site as Alif Suvo

Preserve the existing editorial typography, cinematic photography, neutral palette, whitespace, and restrained motion. Change the identity, structure, and copy so the site presents Alif Suvo as an independent photographer and visual storyteller.

## Changes

- Replace all placeholder identity details with only the approved information: Alif Suvo, Alifpicster@gmail.com, and @Alif_Suvo.
- Remove every invented biography detail, client name, testimonial, review, location claim, credential, and personal fact.
- Simplify navigation to **Work, About, Info, Contact**.
- Rename the portfolio experience to **Work** and let all existing imagery coexist in one editorial, image-led gallery without service-category filters.
- Remove the testimonials page and the separate Families, Couples, and Portraits service pages so the architecture no longer centers commercial categories.
- Update the homepage statement to **“Keep the feeling.”** with the provided supporting copy and a subtle **“Lisbon, Portugal — 2026”** location line.
- Make About intentionally minimal, using only the approved brand positioning and “Currently working from Lisbon.”
- Rename Pricing to **Info**, retain the three existing package structures, and halve displayed prices from €290/€480/€950 to €145/€240/€475. Remove unverified package inclusions rather than replacing them.
- Update Contact with the approved identity and neutral placeholders. Remove response-time promises and other invented claims.
- Update page titles and descriptions to be brand-led and geographically flexible.
