# Lumina Moments

build a premium cinematic portfolio for a Lisbon-based photographer who captures authentic family, couple, and portrait moments. Make it feel Apple-level polished, clean, with lots of white space, smooth animations, and emotional images. Include full-screen hero, subtle parallax, elegant fonts, neutral palette, and clear sections: portfolio, families, couples, portraits, about, pricing, testimonials, seamless booking/contact, and a short tagline: capturing moments you’ll want to relive.
